## 独立审阅及修复

由独立 reviewer 对实现作只读审阅。四个重要发现均已修复：

1. 同步在账号切换时可能上传原账号队列：每次请求重新检查身份，以已验证会话的固定 bearer token 发出请求，响应后再次检查；回归测试确保只发送一次原账号请求。
2. 生成请求 pending 状态可能永久阻止后续请求：增加创建时间和过期租约；本地 PostgreSQL 测试验证恢复。
3. 按条数切批可能超过服务端字节限制：按 UTF-8 字节和条数同时切批；长中文内容测试验证分批。
4. 拼句辅助操作嵌套在词块按钮中：辅助展开移到词块外，桌面与手机测试验证没有嵌套按钮。

后续正式构建测试发现静态缓存的 Vary Origin 匹配问题，限定公开静态资源忽略 Vary 后，离线刷新测试通过。学习记录与下一张位置在本地事务内保存，进入下一张表示保存已完成。

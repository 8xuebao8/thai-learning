# 罗马音辅助标注约定

版本 1。供本应用的词条编辑和显示使用；不是官方泰语转写标准。当前内置内容仍待专业核对，不宣称已通过人工审核。它辅助回忆读音，不替代泰文、真人示范或可靠语音。

## 声调

每个音节末尾记录声调：¹ 中平，² 低，³ 降，⁴ 高，⁵ 升。没有声调标注的条目不应当作完整读音发布。声调类别来自实际读音，不能仅凭罗马音或声母猜测。

## 元音与辅音

重复元音表示长音，如 aa、ii、uu、ee、oo、ɛɛ、ɔɔ、ʉʉ、əə。短元音使用单个对应符号。双元音需逐条核对，字母数量不能机械解释为时长。

kh、ph、th 为送气；k、p、t 为不送气。ng 为鼻音。ɛ、ɔ、ʉ、ə 用来区分英语字母不能准确呈现的元音。尾辅音不追加元音，不把闭塞尾音读成另一个完整音节。连字符表示音节边界，空格用于词或表达单元。

## 编辑检查

核对泰文拼写、音节划分、声调、长短音、送气、尾辅音和语体。保存原始参考出处及访问记录。多音义词需按目标含义核对例句；词条和例句使用同一规范。用户确认和专业审核分别标记。

词块边界用于练习，不声称等于泰语书写中的空格。别把对中文的逐字翻译当成正确泰语语序。仅将已确认的分词和可接受答案收录进题库。

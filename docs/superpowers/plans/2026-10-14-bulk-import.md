# 一次预览确认的批量导入

用户已授权一次上传全部、网页分批处理、一次预览确认，并适配AI提示词。保留现有RPC和账号锁。

- 解析一个完整包、包数组、多个JSON块及多个上传文件；必须来自同一快照。输入保护为20MB/10000操作，不把500设为限额。上传无须用户拆100项。
- 全局预览去重、冲突、主题变化；统一分页展示。主题与词语ID不变，学习记录只读。
- 冻结已确认计划并持久化（访客仅内存）。目录先提交，词语按100条/350KB分批；每批独立回执与固定请求ID；保存阶段和实际进度。跨批非原子，明确告知部分成功。
- 重试先核实回执；恢复未完成任务；每批重新校验账号、epoch、目录、待写词条和全局游标。外部冲突停止，不擅自重做预览或覆盖。确认之前取消不写数据。
- AI优先一个包含全部operations的JSON文件/代码块，不要求模型或用户按云端批次拆包；兼容同快照的旧分包。
- 单元测试大输入/混合输入/限制/全局去重；模拟云端分批、主题依赖、丢失响应、刷新、冲突、账户初始化；桌面手机一次确认流程；构建发布。

# 泰语学习工具首版设计

日期：2026-10-13。状态：供用户审阅，尚未实施或部署。

## 已确认目标

面向用户本人：日常泰语交流没有问题，认识部分泰文。优先扩大词汇量，其次提高阅读能力，再提高表达自然度。手机和电脑均可使用，登录后自动同步。每日目标随时调整。

首版采用内置课程与个人词库结合的方式，主题为工作商务、大学课堂、生活办事。默认并列显示泰文和罗马音，中文按需揭示。Karaoke 指辅助阅读的罗马音，不包含音频同步高亮。罗马音必须区分声调、长短元音等发音要素。

部署使用 GitHub Pages 和 Supabase Free，不租服务器、不启用付费升级。AI 辅助生成只采用经过实际验证的免费服务；不可用时保留手动录入。

## 首版范围

- 首页：到期复习、继续学习、主题课程、目标调整和添加内容入口。
- 词汇：课程及个人词库、筛选、翻卡、前后切换、随机顺序、认识或多练反馈。
- 测验：罗马音选中文、中文选罗马音、听音选词、罗马音选泰文、缺词填空。
- 拼句：中文提示，稳定词块实例，撤回、重置、提示、提交、答案解释和音频。
- 进度：单词与句型独立统计、学习记录、同步状态、设置和导入导出。
- 个人录入：输入泰文，生成可编辑草稿；确认后保存。未经确认的分词与答案不能进入拼句。

建议首批内容目标为每主题约 20 个词语或短语及 8 个句型练习。数量不是发布门槛；没有完成来源核对的内容必须标注草稿，不宣称已经人工审核。

不包含付款、多人社区、排行榜、语音识别评分、逐音节高亮或桌面安装包。

## 技术结构

React、TypeScript、Vite、Tailwind CSS；Hash 路由适配 Pages；IndexedDB 和 Dexie 存储本地数据；Zod 校验数据；Service Worker 缓存离线资源；Supabase 提供 Auth、Postgres 和生成代理 Edge Function。

界面、学习规则、本地持久化、同步和外部服务各自独立。复习与评分逻辑为可单独测试的纯函数。依赖版本在实施时选择兼容稳定版本并锁定。

GitHub Pages 发布构建后的 dist。项目路径同时用于 Vite base、资源路径、Manifest 和 Service Worker 作用域。使用 GitHub Actions 检查、构建、发布，失败时不替换已发布版本。

免费公开仓库仅包含代码、可公开课程、具有授权的资源。私人词库、令牌和服务端秘密不进入仓库或发布文件。

## 内容模型

课程、词条、句型、练习均有稳定 ID 和内容版本。词条包括泰文、罗马音、中文、词性、语体、发音提示、搭配、三语例句和音频引用。

所有内容记录来源、罗马音规范版本、审核状态和修改时间。审核状态区分 AI 草稿、用户确认、内容审核通过。用户确认不等同于专业语言审核。

内置课程使用版本化 JSON；个人内容存数据库；个人对内置内容的修改使用覆盖记录，课程升级不能静默覆盖个人修正。

正式课程录入前必须完成罗马音规范文件与代表性样例核对。规范需覆盖声调、元音长短、送气、尾辅音和音节边界；不采用未经验证的自动转写作为权威。内容审核来源尚未落实，因此当前只能完成数据结构与草稿工作，不能声称审核已完成。

## 学习规则

建议每日顺序为到期复习、新词、小测验、拼句、总结。允许自由进入、退出，保存会话位置。

拼句词块采用唯一实例 ID 和语言 token ID。先检查实例是否重复，再按语言 token 比较已审核的可接受序列；相同文字的可互换实例不能造成误判。提示或揭示答案记录为辅助完成。页面支持三种文字模式及多行词块布局。

音频优先为授权且核对过的静态音频。没有文件时检测设备泰语 TTS，朗读泰文原文；无可用语音时禁用播放并跳过听力题，不阻止课程完成。浏览器 TTS 不承诺离线或跨设备一致。

复习间隔采用 1、3、7、14、30、60 天。到期且无提示答对才推进阶段；答错本轮再次出现，并回到 1 天阶段；辅助完成不推进；同轮重复正确不能跨越多个阶段。新词第一次自评认识仅进入学习阶段。额外练习不反复推迟既有复习日期。

熟练度为新词、学习中、熟悉、已掌握；到期状态由 next_review_at 单独计算。首版建议阶段 0 至 1 为学习中、2 至 3 为熟悉、4 至 5 为已掌握。单词、句型分别记录状态。

事件时间存 UTC；学习日期默认按 Asia/Bangkok 计算。至少一次有效学习事件才计入连续学习日。每日目标变化不追改既有事件和复习日期。

## 本地数据与同步

本地事务同时写入学习事件和待同步操作，再更新界面。待同步队列在登录、回到前台、恢复联网、完成练习及手动同步时处理；不依赖浏览器关闭后的后台任务。

云端保存用户设置、个人词条及修正、不可变学习事件、派生复习状态和同步变更记录。事件使用 UUID 去重，记录设备 ID、设备时间、服务端时间及算法版本。

多设备事件合并后，按明确且一致的排序重算复习状态，不直接覆盖另一台设备的计数。实施计划需规定时钟异常处理及同一到期阶段跨设备重复复习的去重规则，并以双设备测试验证。

编辑采用基础版本检查。冲突保留双方副本供选择，不静默丢弃。删除使用墓碑记录，旧设备不能复活已删除数据。云端增量同步需要按用户串行提交或同等可靠的变更游标，避免并发事务导致跳过记录；拉取支持分页和恢复。

本地数据按账户隔离；访客记录仅在用户明确选择后合入账号。过期会话保留待同步队列，重新登录后继续。服务故障使用退避重试。

## 登录与安全

建议采用 GitHub OAuth 经 Supabase Auth 登录；密码只在 GitHub 官方页面输入。使用 PKCE，回跳到真实存在的项目根路径，在初始化 Hash 路由前交换授权码并清理 URL。

所有私有表启用 RLS，检查 auth.uid 与记录所有者。私人首版以服务端允许名单限制账号，不能仅依靠隐藏入口。同步 RPC、视图和云函数也必须遵守所有者隔离。

前端只包含 Supabase URL 和 publishable key。AI 密钥及 OAuth client secret 保存在云端秘密配置；不放入 VITE 环境变量、代码、日志、备份或 dist。

AI 与导入内容作为文本渲染；拒绝不合规结构和危险资源 URL。不接无关第三方脚本。退出提供本机数据清除选项，清除未同步记录前明确提示。

## 免费生成辅助

生成接口输入泰文、内容类型、罗马音版本和 requestId，输出中文、罗马音、例句、提示及警告。服务适配器允许更换供应商。

云函数验证真实登录身份及允许名单，再执行输入限制、服务端限流、幂等检查和结构校验。初始上限建议为每次 500 字符、每日 20 次；调用失败不自动无限重试。有效用户令牌验证不能由 CORS 或公开项目 key 替代。

实际免费模型需要用用户账号验证地区、额度、结构化输出和泰语质量后才启用。用户主动发起生成才上传输入，显示服务方及数据用途说明。超额或不可用时保留表单并允许手动录入。

## 离线与备份

缓存应用外壳、字体、已下载课程和音频，不缓存认证响应。首次登录、同步和在线生成需要联网。界面明确区分已下载、可离线和需要联网。

JSON 备份包含格式版本、词库、覆盖记录、学习事件和设置，不含令牌与密钥。导入校验后按 ID 合并，并支持导入前备份。同步不是历史备份；免费数据库不作为唯一数据副本。

更新提示在练习结束后出现；本地数据库使用版本迁移。回滚前验证数据格式兼容性，不能以清空本地数据库解决升级问题。

## 验收

- 四个主页面可使用，手机词块换行、点击退回及键盘操作正常。
- Pages 子路径资源正确，刷新、OAuth 回调均正常。
- 无网络仍可学习下载内容并保存事件；恢复后准确同步。
- 双设备重复上传、并发复习、冲突编辑和删除恢复不会丢数据或重复计分。
- 未登录及非允许账号不能读取或修改私有数据；模拟改写所有者 ID 仍被拒绝。
- 无音频、生成超时和免费限额不会阻碍手动学习。
- 课程内容有可追溯来源及真实审核标记；罗马音规范与数据一致。
- 导出恢复、版本迁移、更新后继续学习可验证。
- 发布构建不含秘密，检查和测试失败不发布。

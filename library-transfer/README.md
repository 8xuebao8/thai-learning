# AI 词库复制与导入

替代此前 MCP 首版，直接在词汇学习页使用。业务源码及测试位于 src/library-transfer/。

## 使用

1. 点击“复制词库＋AI 提示词”，将当前完整词库（含可恢复的软删除词条）和格式规范交给 AI。同时包含学习目标、逐词及拼句进度和完整练习历史（只读），不含登录信息、设备标识。学习上下文不允许通过修改包写回。
2. 与 AI 讨论、提取或调整。要求它最终输出变化清单及完整 JSON 修改包。
3. 回到同一浏览器、同一账号，点击“导入 AI 修改”，粘贴并预览。
4. 弹窗显示新增、修改前后、删除、恢复，以及重复或错误。取消不保存；有错误或冲突时整批禁止提交。
5. 确认后登录用户提交云端，访客只临时保存。成功回执逐条展示，重复粘贴不重复新增。

每包最多100项/250KB。字段与提示词以 src/library-transfer/contract.ts 为唯一运行时来源。完整库很大时可能超过模型上下文，需要自行分批讨论；当前不支持跨浏览器传递快照。

## 数据约定

- format=thai-library-changes，version=1，snapshotId 原样保留。
- add: data；update: id+expectedVersion+changes；delete/restore: id+expectedVersion。
- 已有词按 ID 定位，不因缺省某个词而删除。新增 ID 由修改包摘要+操作索引生成。
- 中文、读音不齐全为 pending，不进入学习。sentence 使用现有词块结构，整句和词块需完整、一致。
- 所有 AI 内容为草稿，语言正确性仍需核对。
- 软删除保留词条和学习事件，可使用新导出的快照 restore；账号初始化仍是网页已有两次确认流程。

## 云端部署

依次应用 supabase/migrations/202610140004_library_import.sql 和 202610140005_custom_themes.sql，再部署网页构建。没有部署 SQL 时，登录用户导入会明确报错，不会假报成功。

RPC import_learning_changes 绑定 auth.uid 与已有允许名单，使用账号游标行锁，在同一事务内检查 epoch、全局序号和每条版本，再写词条及同步日志。冲突整批不写。私有回执表按账号、epoch、修改包摘要去重；get_learning_import_receipt 用于恢复响应丢失的成功记录。无新密钥、无模型 API、无新账号权限。

## 验证记录

设计依据：用户已确认复制→AI讨论→粘贴→逐项预览→确认/取消，包含拼句和删除/恢复。本轮“开始吧”授权实施。

- 已验证新契约、guest不落盘/重复导入、不同修改包隔离、数据库冲突原子性、丢失响应回执恢复。
- 独立审查发现新增 ID 冲突（已用回归测试修复）和拼句选中词块失效（已重现并修复）。
- 最终回归：40 项单元/数据库测试、46 项桌面/手机测试、2 项生产离线测试通过。
- SQL 已在新加坡项目执行成功；线上网页发布验收结果以交付说明为准。

## 自定义主题

词汇页「管理主题与移动词语」支持新建、重命名、删除并迁移，以及每批最多100个词的移动。词语编辑器也可选择所属主题。首页、词汇筛选、拼句练习统一使用主题目录。

主题数据放在 settings.themes，目录含原始四个主题及自定义主题，最多200项（含历史迁移记录）。删除主题需选择迁往的有效主题；保留 redirectTo，旧词、软删除后恢复的词和内置拼句会解析到新归属。personal 是不可删除但可重命名的归档主题。不改变词条/练习ID或学习历史。单独的内置拼句不支持 move，个人拼句随词条移动。

AI 修改包增加 theme_add {id,name}、theme_rename {id,name}、theme_delete {id,moveTo}、move {id,expectedVersion,theme}；ID为custom:加1–64位字母数字下划线/短横线，名称1–60字且唯一。复制提供完整目录、有效词条归属及只读学习上下文。每主题最多一个操作，新建在引用之前，删除目录不会删除词条。预览列出名称前后变化和每个受影响内容的最终去向。

import_learning_changes_v2 在原有账号锁、版本、游标、epoch及回执机制内原子保存主题和词条。只允许更改设置中的themes，学习目标等字段不可随导入修改。旧版客户端提交未含themes的设置时服务端保留已有目录。部署后需更新网页使用自定义主题。

## AI 生成质量与交接

默认生成完整可学习词条，每批20个，正文提供一个完整JSON代码块；“开始生成/输出格式”等触发直接生成，不仅给链接或示例。读音、中文、词性、用法和例句必须填写真实内容，不能可靠核实的词放到包外待核实清单。只有用户明确允许只收录原词时才输出不完整词条。网页预览逐项标出缺读音/中文与本批待补全数。此提示词不能保证外部模型遵从或语言准确，导入仍需人工核对。学习记录不被改动。
